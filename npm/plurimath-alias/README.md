# plurimath

The unscoped alias for
[`@plurimath/plurimath`](https://www.npmjs.com/package/@plurimath/plurimath) —
the native TypeScript implementation of
[Plurimath](https://github.com/plurimath/plurimath): parse and render
AsciiMath, LaTeX, UnicodeMath, MathML, OMML and HTML.

```sh
npm install plurimath
```

Every export re-exports the scoped package; subpath entries
(`@plurimath/plurimath/asciimath`, `/mathml`, `/latex`, …) are available
through the scoped name only. The version matches the scoped package it
depends on.
